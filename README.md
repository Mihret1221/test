SovereignID: Enterprise Identity & Access Management API

A stateless, micro-segmented security engine built using **FastAPI** and **Docker** to handle global user authorization constraints.

Features
Stateless Authentication:** Cryptographically signed HMAC-SHA256 JWT tokens.
Secured Hashes:** Salted account provisioning backed by industry-standard `bcrypt`.
Granular RBAC Middleware:** Restricts traffic automatically by scanning user data clearance tags.
